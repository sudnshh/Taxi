# تكسي وين — نسخة تجريبية مع خريطة العراق

ارفع جميع الملفات في جذر مستودع GitHub Pages. افتح index.html.

- customer.html: تحديد الانطلاق والوجهة بالنقر على خريطة OpenStreetMap، مع خيار الموقع الحالي.
- driver.html: عرض وقبول الطلبات المحفوظة محلياً على نفس المتصفح، وفتح مسار خارجي.
- admin.html: إحصاءات تجريبية محلية غير محمية.

**مهم:** لا يوجد Backend أو تسجيل دخول أو تتبع حي أو تسعير أو توزيع طلبات حقيقي. localStorage لا يزامن بين أجهزة مختلفة. خط الخريطة متقطع للتوضيح وليس مسار طريق فعلي. تحتاج اتصال إنترنت لتحميل الخريطة. خرائط OSM العامة تخضع لسياسة استخدام البلاطات؛ عند التوسع يجب اختيار مزود مناسب.
